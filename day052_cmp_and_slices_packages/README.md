# Day 52: cmp & slices & maps 패키지

## 개념 설명 섹션
Go 1.21 버전에서 표준 라이브러리 `slices`, `maps`, `cmp` 패키지가 새로 도입되었습니다. 이 패키지들은 기존에 개발자가 직접 구현하거나 불필요한 boilerplate 코드를 작성해야 했던 일반적인 컬렉션 작업을 표준화하고 최적화하였습니다. `slices`는 슬라이스의 정렬, 역순, 복사, 삭제 등 빈번히 사용되는 연산을 제공하며, `maps`는 맵의 키와 값을 슬라이스로 추출하거나 조건에 따라 키를 삭제하는 기능을 안전하게 수행할 수 있게 해줍니다.

`cmp` 패키지는 제네릭 프로그래밍의 핵심 도구입니다. `cmp.Compare[T]` 함수는 두 값을 비교하여 -1, 0, 1을 반환하는 함수 객체를 생성하며, 이를 `slices.SortFunc`와 결합하면 복잡한 커스텀 정렬 로직을 간결하게 작성할 수 있습니다. 또한 `cmp.Ordered`는 타입 제약 조건(Type Constraint)으로, `<`, `>`, `==` 등 비교 연산자가 지원되는 모든 기본 타입(int, float, string 등)을 포괄합니다. 이를 통해 제네릭 함수 작성 시 중복 타입 선언 없이 유연한 타입 가용성을 확보할 수 있습니다.

이 세 패키지는 상호 연계되어 동작합니다. 예를 들어 `maps.Keys`로 추출한 키 슬라이스에 `slices.Sort`를 적용하거나, `cmp.Compare`를 활용한 정렬 로직을 `slices.SortFunc`에 전달하는 등 현대 Go의 컬렉션 처리 패러다임을 완성합니다. 표준 라이브러리가 이러한 기능을 내장하면서 코드 가독성과 실행 성능이 모두 향상되었습니다.

## 코드 설명 섹션
- **slices.Sort / Contains / Reverse**: `numbers` 슬라이스에 `slices.Sort`를 적용해 오름차순 정렬한 후, `slices.Contains`로 특정 값의 존재 여부를 불리언으로 확인합니다. `slices.Reverse`는 인덱스 기반 반복문보다 명확하게 슬라이스를 뒤집습니다.
- **maps.Keys / Values**: `maps.Keys`와 `maps.Values`는 맵의 키와 값을 각각 새로운 슬라이스로 반환합니다. 맵의 순서가 보장되지 않으므로, 키 슬라이스를 반환받은 후 `slices.Sort`를 적용하여 출력 순서를 고정했습니다.
- **cmp.Compare**: 두 값의 크기를 비교하는 제네릭 함수입니다. 첫 번째 인자가 작으면 `-1`, 같으면 `0`, 크면 `1`을 반환하며, 직접 호출하거나 `slices.SortFunc`의 비교 함수로 전달할 수 있습니다.
- **cmp.Ordered**: 제네릭 타입 매개변수 `[T cmp.Ordered]`는 비교 연산이 가능한 타입을 받도록 제약합니다. `sumOrdered` 함수는 `int`나 `float` 등 `Ordered`를 만족하는 타입의 슬라이스를 받아 안전하게 합계를 계산합니다.

## 핵심 포인트 섹션
- `slices`와 `maps` 패키지는 맵과 슬라이스 처리에 필요한 핵심 연산을 표준화하여 코드 가독성과 안정성을 높였습니다.
- `cmp.Compare[T]`는 제네릭 비교 로직을 재사용 가능한 함수로 제공하며, `slices.SortFunc`와 자연스럽게 통합됩니다.
- `cmp.Ordered`는 `<, >, ==` 연산을 지원하는 기본 타입을 포괄하는 타입 제약으로, 제네릭 함수의 타입 범위를 효율적으로 정의합니다.
- `maps.Keys`와 `maps.Values`는 맵의 내부 데이터를 복사하여 슬라이스를 반환하므로, 원본 맵의 순서나 구조에 영향을 주지 않습니다.
- Go 1.21 이상 환경에서 이 패키지들을 활용하면 중복 코드를 제거하고 타입 안전성(Type Safety)을 유지한 채 고성능 컬렉션 연산을 구현할 수 있습니다.
