# Day 53: range over func (Go 1.23)

## 개념 설명
Go의 `range` 구문은 슬라이스, 맵, 채널 등에 국한되지 않고 함수 반환값에도 적용될 수 있도록 확장되었습니다. 이 기능의 핵심은 `iter` 패키지에 정의된 `iter.Seq[T]`와 `iter.Seq2[K, V]` 타입입니다. `iter.Seq[T]`는 `func(yield func(T) bool)` 타입의 별칭이며, `iter.Seq2[K, V]`는 `func(yield func(K, V) bool)` 타입의 별칭입니다. 기존에 함수를 호출한 결과에 `for ... range`를 적용하면 컴파일러가 해당 함수를 자동으로 실행하고, 반환된 함수의 `yield` 콜백을 내부적으로 처리하는 루프로 변환합니다.

커스텀 이터레이터를 구현할 때는 `yield` 함수를 호출하여 값을 외부로 전달합니다. `yield` 함수는 전달받은 값을 받으면 `true`를 반환하여 루프를 계속 진행하게 하고, `false`를 반환하면 즉시 루프를 종료시킵니다. 이를 통해 `break` 또는 `continue`와 같은 제어 흐름을 자연스럽게 구현할 수 있으며, 메모리 전체를 한 번에 할당하는 슬라이스 대신 필요할 때마다 값을 생성하는 지연 평가(Lazy Evaluation) 패턴을 구현할 수 있습니다.

또한 `iter` 패턴은 내장 라이브러리(`slices`, `maps`, `channels` 등)의 모든 함수에 자동으로 적용됩니다. 개발자가 직접 `iter.Seq` 반환 함수를 작성하지 않아도 `range` 구문을 사용하면 내부적으로 이터레이터 함수가 호출되므로, 기존 코드 수정 없이 더 간결하고 효율적인 반복문을 작성할 수 있습니다. 이는 데이터 파이프라인 구축이나 커스텀 컬렉션 구현 시 매우 유용한 패턴으로 자리 잡았습니다.

## 코드 설명
- `countSeq`와 `evenSeq`: `iter.Seq[int]`을 반환하는 커스텀 함수입니다. `yield` 콜백을 호출하여 정수 값을 순차적으로 전달하며, `evenSeq`는 짝수 조건을 만족할 때만 `yield`를 호출하여 필터링 효과를 구현합니다.
- `pairSeq`: `iter.Seq2[int, string]`을 반환하며, 슬라이스의 인덱스와 값을 동시에 `yield` 함수의 두 인자로 전달합니다. `for idx, lang := range pairSeq(data)` 구문은 이를 자동으로 해독하여 변수에 할당합니다.
- `main` 함수: 각 이터레이터를 호출하고 `range` 구문과 결합하여 출력값을 생성합니다. `break` 문을 사용할 경우 내부적으로 `yield`에 `false`를 전달하는 방식으로 루프가 안전하게 종료됨을 보여줍니다.

## 핵심 포인트
- `iter.Seq[T]`는 `func(yield func(T) bool)` 타입으로, 커스텀 이터레이터의 표준 시그니처입니다.
- `for x := range func() {}` 구문은 함수를 호출하고 반환된 이터레이터 함수를 자동으로 실행합니다.
- `yield` 함수는 값을 전달하고 루프 계속 여부를 제어하는 핵심 메커니즘으로, `break`/`continue`의 기초가 됩니다.
- 내장 패키지의 함수도 동일한 패턴으로 동작하므로 별도의 추가 학습 없이 즉시 적용 가능합니다.
- 지연 생성(Lazy Evaluation) 특성을 활용하여 메모리 효율적인 데이터 처리 파이프라인을 설계할 수 있습니다.
