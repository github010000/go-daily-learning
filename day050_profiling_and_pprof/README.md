# Day 50: 프로파일링과 pprof

## 개념 설명
Go 언어로 고성능 서비스를 개발할 때, 단순히 코드가 정상적으로 작동하는 것을 넘어 효율적인 자원 사용을 확인하는 것이 필수적입니다. `net/http/pprof`는 Go 표준 라이브러리에서 제공하는 프로파일링 데이터 노출 기능으로, HTTP 엔드포인트를 통해 실행 중인 프로그램의 CPU 사용량, 메모리 할당, goroutine 수, 뮤텍스 경쟁 상태 등을 실시간으로 모니터링할 수 있게 해줍니다. 이는 서비스 운영 중 발생할 수 있는 성능 병목 지점이나 메모리 누수를 사전에 찾아주는 강력한 도구입니다.

수집된 프로파일 데이터는 `go tool pprof` 명령어를 통해 분석합니다. 이 내장 도구는 `.prof` 파일을 시각화하거나 텍스트로 변환하여, 어떤 함수가 가장 많은 CPU 사이클을 소비하거나 메모리를 할당하는지 명확히 보여줍니다. 특히 `go test` 실행 시 `-cpuprofile`이나 `-memprofile` 플래그를 결합하면 벤치마크 과정에서 자동으로 프로파일 파일을 생성할 수 있어, 단위 테스트 단계에서 코드 최적화의 효과를 정량적으로 검증하고 비교할 수 있습니다.

실제 서비스나 애플리케이션에서는 `net/http/pprof` 패키지를 사이드 이펙트 임포트하고 HTTP 서버에 라우팅하여 외부에서 접근할 수 있도록 구성합니다. 개발 환경이나 내부 네트워크에서는 이 엔드포인트를 통해 `profile`, `heap`, `goroutine` 등 필요한 유형의 프로파일을 다운로드한 후 `pprof` 도구에 전달하면 됩니다. 프로파일링은 일회성 점검이 아닌 CI/CD 파이프라인이나 모니터링 시스템에 자동화하여 지속적인 성능 건강 상태를 관리하는 것이 산업 표준입니다.

## 코드 설명
- **`net/http/pprof` 임포트**: `_ "net/http/pprof"` 문법으로 사이드 이펙트 임포트를 수행하여, Go 런타임이 자동으로 `/debug/pprof/` 관련 HTTP 핸들러를 등록하도록 합니다. 별도의 라우팅 코드 없이도 프로파일링 엔드포인트가 즉시 활성화됩니다.
- **CPU 프로파일 수집 (`runtime/pprof`)**: `pprof.StartCPUProfile()`로 기록을 시작하고, 분석 대상 함수(`cpuHeavyWork`)를 실행한 후 `pprof.StopCPUProfile()`로 기록을 종료합니다. 생성된 파일에는 호출 스택과 CPU 사이클 분포 정보가 포함됩니다.
- **메모리 프로파일 수집**: 정확한 힙 메모리 분석을 위해 `runtime.GC()`를 두 번 강제 호출하여 가비지 컬렉션을 유도한 후, 목표 함수(`memoryHeavyWork`)를 실행합니다. 그 후 `pprof.WriteHeapProfile()`로 현재 메모리 할당 상태를 파일에 저장합니다.
- **`go tool pprof` 사용법 안내**: 생성된 `.prof` 파일을 명령줄에서 분석하거나, HTTP 엔드포인트를 직접 전달하여 브라우저(`-web` 플래그)나 텍스트(`-text` 플래그) 형태로 결과를 확인하는 방법을 상세히 출력합니다. 벤치마크 옵션 연동법도 함께 안내합니다.

## 핵심 포인트
- `net/http/pprof`는 사이드 이펙트 임포트(`_`)를 통해 자동으로 HTTP 프로파일링 엔드포인트를 제공하며, 프로덕션 환경에서는 반드시 인증 및 IP 제한을 적용해야 합니다.
- CPU 프로파일링은 `StartCPUProfile/StopCPUProfile`을, 메모리 프로파일링은 `runtime.GC()` 후 `WriteHeapProfile`을 사용하여 정확한 할당 데이터를 수집해야 합니다.
- `go tool pprof -web` 명령어로 브라우저에서 인터랙티브한 호출 스택 트리를 분석하거나, `-text`로 가장 높은 비용을 차지하는 함수를 빠르게 파악할 수 있습니다.
- 벤치마크(`go test -bench=.`) 옵션에 `-cpuprofile`과 `-memprofile`을 결합하면 테스트 실행 중 자동으로 프로파일 파일을 생성하여 최적화 효과를 정량 비교할 수 있습니다.
