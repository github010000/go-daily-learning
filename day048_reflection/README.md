# Day 48: 리플렉션(Reflection)

## 개념 설명
Go 언어의 리플렉션(Reflection)은 런타임에 프로그램의 타입과 값을 동적으로 조사하거나 조작할 수 있는 기능입니다. 컴파일 시점에 타입이 고정되는 Go의 철학과는 달리, `reflect` 패키지를 제공하여 메타데이터 기반의 유연한 처리가 가능하게 합니다. 이는 주로 시리얼라이저, ORM, API 게이트웨이 등 데이터 형식을 동적으로 처리해야 하는 프레임워크 개발에 필수적으로 활용됩니다.

리플렉션의 진입점은 `reflect.TypeOf()`과 `reflect.ValueOf()`입니다. `TypeOf`는 변수의 타입 정보를 담고 있는 `reflect.Type`을 반환하며, `ValueOf`는 변수의 실제 값 정보를 담고 있는 `reflect.Value`를 반환합니다. 반환된 객체는 `Kind()` 메서드를 통해 구조체, 정수, 문자열, 슬라이스 등 기본 형태를 판별할 수 있어, 타입별 조건 분기나 안전한 조작의 기준이 됩니다.

구조체 태그(Tag) 읽기와 필드 접근은 실제 개발에서 가장 빈번하게 쓰이는 리플렉션 패턴입니다. `Field(i).Tag.Get("json")`을 호출하면 구조체에 선언된 태그 문자열에서 원하는 키의 값을 추출할 수 있으며, `Field(i).Interface()`를 통해 실제 값을 가져올 수 있습니다. 다만 리플렉션은 컴파일 타임 타입 검사를 우회하고 인터페이스 타입을 통하는 오버헤드가 발생하므로, 애플리케이션 핵심 로직이 아닌 반드시 필요한 경우에 한해 신중하게 사용해야 합니다.

## 코드 설명
- `reflect.TypeOf(p)`와 `reflect.ValueOf(p)`를 호출하여 구조체 인스턴스의 타입과 값을 분리합니다.
- `t.Kind() == reflect.Struct` 체크로 안전성을 확보한 후, `t.NumField()` 루프로 각 필드를 순회합니다.
- `field.Tag.Get("json")`으로 태그의 키를 추출하고, `value.Interface()`로 런타임 값을 얻습니다.
- 추출된 키-값 쌍을 문자열로 조합하여 `{"full_name": "홍길동", ...}` 형태의 간단한 직렬화 결과를 출력합니다.

## 핵심 포인트
- `reflect.TypeOf`은 타입 메타데이터를, `reflect.ValueOf`는 실제 데이터 값을 반환하므로 목적에 맞게 구분해야 합니다.
- `Kind()` 메서드는 `reflect.Struct`, `reflect.Int` 등 기본 타입을 구분할 때 사용하며, `reflect.Type` 비교보다 우선되어야 합니다.
- `Tag.Get("json")`은 구조체 태그에서 특정 키의 값을 추출하는 표준 라이브러리 방식입니다.
- 리플렉션은 실행 속도가 느리고 버그 유발 가능성이 높으므로, 프레임워크 내부 구현 등 필수적인 경우에만 제한적으로 사용해야 합니다.
