# Day 56: text/template & html/template

## 개념 설명
Go 언어의 `template` 패키지는 정적인 텍스트나 동적인 웹 페이지를 생성하는 강력한 도구입니다. 프로그래밍 로직을 분리하고 뷰(View) 계층에서 데이터 표현을 담당할 때 필수적으로 사용됩니다. 기본적으로 `text/template`와 `html/template` 두 가지 패키지가 제공되는데, 전자는 일반 텍스트용이며 후자는 HTML을 자동으로 이스케이프 처리하여 보안(XSS 공격 등)을 강화합니다.

템플릿 파일 내에서는 중괄호 `{{ }}` 안에 "액션(Action)"을 작성하여 데이터에 접근하거나 로직을 제어합니다. 예를 들어 `{{.Name}}`은 현재 데이터의 Name 필드를 의미합니다. 이 패키지는 파이프라인(Pipeline) 문법을 지원하여, 데이터에 여러 함수를 연속 적용할 수 있습니다. 또한 `{{if}}`, `{{range}}`, `{{with}}` 등의 조건문과 반복문을 통해 복잡한 레이아웃을 구현할 수 있습니다.

특히 `html/template` 패키지의 가장 큰 특징은 컨텍스트 인식 자동 이스케이프(Context-Aware Auto-Escaping)입니다. 템플릿 엔진은 해당 데이터가 HTML 본문, JavaScript, CSS 등 어디에 삽입될지를 파악하여 자동으로 특수 문자를 변환합니다. 이를 개발자가 일일이 `html.EscapeString`을 호출하지 않아도 되므로, 웹 애플리케이션의 보안 코드를 간소화할 수 있습니다.

## 코드 설명
- **데이터 구조체**: `Post` 구조체를 정의하여 템플릿에 전달할 데이터를 캡슐화했습니다.
- **템플릿 문자열**: HTML 구조 내에 `{{.Title}}`과 `{{.Content}}`를 배치했습니다.
- **`template.New().Parse()`**: 템플릿을 메모리에 파싱하여 실행 가능한 객체로 변환합니다.
- **`Execute()`**: 파싱된 템플릿과 데이터를 결합하여 결과물을 `os.Stdout`으로 출력합니다. `Content` 필드에 `<script>` 태그가 포함되어 있음에도 불구하고, `html/template`가 이를 안전한 문자열로 변환하여 출력함을 확인할 수 있습니다.

## 핵심 포인트
- `html/template`는 XSS 방지를 위해 자동으로 HTML 문자를 이스케이프합니다.
- `{{ .Field }}` 문법을 사용하여 구조체의 필드 값에 접근할 수 있습니다.
- 템플릿 엔진은 데이터를 대입할 때 정적 텍스트와 동적 데이터를 분리하여 관리합니다.
- 파이프라인 `{{ .Field | Func }}`을 통해 데이터 변형을 간편하게 처리할 수 있습니다.
